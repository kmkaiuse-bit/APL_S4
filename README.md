# APL S4：AI 教學互動站

教師學生學習追蹤的後端程式放在 [teacher-progress](teacher-progress/README.md)。它需Python及另行提供的私人SQLite資料庫；不會由GitHub Pages執行，也不包含學生紀錄或密碼設定。

以繁體中文呈現第一堂的學生實操、可複製 prompt 及個人紀錄。

## 2.2 AI與社交媒體：第1堂

入口：[2.2 第1堂：演算法點選中你？](2-2-lesson-1/index.html)。網站放在獨立目錄 `2-2-lesson-1/`，包含五部分：相似推薦與排序、數據與資訊缺口、腳本與AI、修訂與互評、查證與轉用。

學生在最後第05部分按「下載全堂PDF」，一次匯出五部分紀錄；前四部分不顯示PDF下載按鈕。小活動一次展開一項。答案保存在自己的瀏覽器，沒有雲端交收或自動呼叫AI；真實AI回答須另用校方允許的工具取得。

這個目錄只包含可公開的靜態網站、AI生成虛構情境圖及第三方授權文件，不包含PPT、教師講稿、學生作答或私人測試檔。

## 2.1 第一堂內容

- `2-1-lesson-1.html`：AI 概念、RCTC、Prompt 實作（原首頁保留）。
- `recognition.html`：作品辨認、觀察及來源反思。
- `generation.html`：生成原理及實操。
- `detective.html`：來源查證、支持內容與證據不足。
- `responsibility.html`：用途風險、幻覺與深偽、交換證據及獨立轉用。

各部分可連續前進及返回。網站不直接呼叫 AI，也不要求輸入 API key。學生複製 prompt 到校方允許的工具，再保留實際輸出及自己的核對理由。

## 開啟

直接在瀏覽器開啟 `index.html`，不需要建置或安裝套件。保留所有 HTML、JS、CSS 及 `assets`。

若要透過 GitHub Pages 發布，可在 repository 的 Settings → Pages 選擇從 `main` 分支的根目錄部署。本次提交網站檔案不代表已啟用 Pages。

## 資料與授權

學生文字只嘗試保留在自己的瀏覽器 localStorage，不會自動提交。請複製／下載備份，按課堂指定方式交付。共用電腦可能讓其他使用者看到保留內容，各部分需分別清除。

五個部分均可下載各自的 A4 PDF，檔名含部分編號與名稱，例如 `第一堂_第03部分_生成原理_學習紀錄.pdf`。PDF 在本機生成、中文以高解像頁面影像保留；需要可複製文字時，使用「複製紀錄」。未填及未完成狀態照實保留，圖片原檔另交。

只使用公開的非個人資料或虛構資料，不輸入真實個人或客戶資料。外部 AI 工具及來源連結需要網絡；使用須符合校方規則。

Lucide 圖示授權見 `LUCIDE-LICENSE`。外部作品、研究素材及政府原文的來源見相關活動頁；其權利仍屬原權利人。本 repository 未授予這些素材新的通用授權。

本機 PDF 匯出使用 pdf-lib，授權見 `PDF-LIB-LICENSE.md`。

更多使用方式與限制見 `使用與驗證.md`。此 repo 只包含網站，不包含教學 PPT、講稿、學生紀錄或私有測試檔。


## 2.2 第2堂：7仔社交影片分析室（10月28日）

學生入口：[2-2-lesson-2/index.html](2-2-lesson-2/index.html)。教師檢視：[2-2-lesson-2/teacher.html](2-2-lesson-2/teacher.html)。

四段任務：獨立比較、取得AI分析、深入核對與兩句建議、個人轉用與修正。提供固定CSV、六則原片縮圖、可複製AI指令、瀏覽器草稿保存、JSON備份還原及HTML／文字報告。教師可批次匯入學生JSON檢視完成狀態並匯出CSV。

教師檢視、教師示範Prompt及抽籤工具已加入密碼解鎖：HTML內容以AES-256-GCM加密，PBKDF2-SHA256衍生金鑰，不在Git保存明文密碼。登入狀態只保留於目前分頁sessionStorage，8小時到期，可主動登出；需要HTTPS或localhost。這是靜態內容加密，不是伺服器帳號或權限系統，也不會移除Git歷史中已公開的舊內容。沒有中央收件與跨裝置同步；學生仍須自行提交。初答封存供學習紀錄，不是防作弊保證。

維護教師頁時，請編輯工作區 `.codex-build/teacher-page-sources/` 內的三份原始HTML，再用 `.codex-build/protect_teacher_pages.py` 加密輸出至本倉庫；建置密碼透過環境變數 `HKIT_TEACHER_BUILD_PASSWORD` 提供。這些原始HTML及建置程式在本Git倉庫外，不應複製明文版本或密碼進公開目錄。只改公開的CSS／JS不需重新加密HTML。其他頁面的公開教學數據仍可正常存取。

原帖：7-Eleven Hong Kong；使用2026年10月26日固定快照。來源連結及圖片出處見網站資料區與assets/thumbnail-sources.json，圖片權利屬原權利人，未授予新的通用授權。網站不直接呼叫AI、不需API key、不把學生回答傳到第三方；公開部署目錄不含學生紀錄。

## 預設首頁（2026-10-28課堂）

網站根目錄 `index.html` 會直接進入 `2-2-lesson-2/`，學生不用選課。原2.1首頁保留於 `2-1-lesson-1.html`，原課堂檔案及學生本機紀錄不變。

## 第2堂Bonus個人選做：15–20分鐘

「換一個指標，你給7仔的建議會改嗎？」直接沿用今堂6則7仔原片固定數據：預測、自己計算Y03與Y02的每千次觀看讚好數、展開六則公式核對、拆解教師自編過度推論，再說明是否調整任務03的建議。全程個人完成，不設互查，不另開商品或寫字幕情境。

18分鐘分為3／6／5／4分鐘；15分鐘可用2／5／4／4，20分鐘用3／7／5／5。教師有餘裕才開放，保留最後個人作答與匯出，不延長原課堂。比值排名、讚好總數、題材因果與銷售效果分開處理。

Bonus不計入四段主要任務完成度，原建議與封存初答不覆寫；舊JSON可照常匯入。新增欄位隨JSON、HTML、文字報告及教師匯入檢視保留，CSV另列Bonus狀態。先前未發布的開場設計草稿欄位只保留在JSON中，不列為新Bonus完成項。

## 教師抽籤工具

第2堂教師頁提供獨立的 `2-2-lesson-2/draw.html`：貼上出席名單（每行一人）或產生座號，按一次抽一位，同一輪不重複；可重開一輪、查看次序、清除本機名單，並切換大字投影模式。名單及紀錄只存在此瀏覽器localStorage，不從學生資料庫取人名，也不會上傳；程式碼不內含真實名單。投影頁不顯示教師核對答案。

## HKIT CMS交收指引

第2堂新增 `#submit`，首頁、側欄、任務04與教師頁均有入口。提供學校ApL CMS直接登入連結及由HKIT首頁進入的路徑，連接本堂JSON／HTML匯出、下載檔案識別、指定作業上傳、儲存／最後提交和狀態確認。登入入口路徑依教師提供的截圖；指定課程為T2026C-APLECC27-29_TLLF-D（course id=11），「數據應用」下的Student Progress（assignment id=79）；提供兩個學生閱讀入口，不包含編輯連結或工作階段參數。允許格式及提交要求以CMS實際頁面為準。

本站不收取CMS密碼或身份證資料、不自動登入或上傳、不宣稱已收到CMS提交。公開檔案不包含教師截圖中的學生編號名單或首次密碼推算方式。上傳操作與Draft／Submitted區分參考Moodle官方說明：https://docs.moodle.org/404/en/Viewing_an_assignment 。

## 第2堂統一PDF交收

學生的主交收按鈕統一為「下載完整PDF紀錄」：四段任務、原初答、核對後修訂、建議卡及Bonus（如有）合併為一份A4 PDF，在本機產生。CMS指引改為直接上傳該PDF，不需自行列印轉檔；JSON移至進階還原備份。

為讓中文在離線環境可靠保留，PDF以高解析頁面影像呈現，並附上 `learning-record.json` 原始紀錄。教師頁可匯入本站產生的完整PDF讀回附件，也接受舊JSON；不會聲稱可自動解析任意PDF或以附件證明身份／答案真確。pdf-lib沿用既有本機程式庫及授權，沒有外部字體或網絡轉檔。
