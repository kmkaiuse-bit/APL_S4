# 教師學生學習追蹤

以Python本機服務及SQLite保存每位學生的課堂紀錄、原作業、證據、白話前後比較與教師跟進。網站先要求登入；學生資料、PDF、JSON匯出、完整備份及寫入操作皆由伺服器驗證登入狀態。

此目錄只提交程式碼，不含真實學生姓名、分析內容、作業、資料庫或使用中的密碼設定。原有靜態教學網站的首頁及課堂入口保持不變。

## 執行

需要Python 3.11或以上，使用標準函式庫，不需安裝第三方套件。

1. 由教師把私人資料庫備份另行放到此目錄，檔名為 `學生學習紀錄.sqlite3`。資料庫不經Git傳送。
2. 執行 `python 設定密碼.py`，以隱藏輸入設定及確認密碼。此步會建立已被Git忽略的 `登入設定.json`；只保存密碼雜湊與隨機鹽值。
3. 執行 `python server.py`。
4. 打開 <http://127.0.0.1:8767/>，輸入密碼。

缺少私人資料庫或登入設定時，服務不會開放學生資料。伺服器只監聽本機127.0.0.1；更改密碼後須重啟服務，既有登入也會失效。

## 同事閱讀流程

首頁先交代課堂活動、閱讀方法和常見題目背景。選學生後可看兩堂表現、作業例子及下一步；需要時展開原作業和詳細分析。可追加日期、任務、證據、協助程度與練習結果，跟進寫入SQLite，重新整理或重啟後仍保留。

白話學生說明從私人資料庫的 `colleague_notes` 表讀取。舊資料庫若沒有此表，仍可讀取原課堂摘要。網站不會自動把未確認身份當成同一人，也不會把缺少作業當作退步。

## 備份及登入

登入後可下載包含原PDF、OCR及跟進紀錄的完整SQLite備份；JSON匯出供閱讀或其他分析，不含原PDF二進位內容。教師跟進採追加保存，不覆寫舊紀錄。備份及登入設定不要提交到儲存庫。

登入最長8小時，可手動登出。密碼用PBKDF2-HMAC-SHA256及隨機鹽值保存；短時間連續輸錯會暫停嘗試。此登入保護適用網站，不代表本機資料庫或下載備份已加密。

## 與GitHub Pages的關係

這是Python／SQLite服務，**GitHub Pages不能執行此後端**。Push此目錄只保存程式碼，不會把私人學生資料庫發布成可跨電腦使用的網站。若要讓同事從其他電腦共用，須另行部署到受控的後端主機、啟用HTTPS，並透過私人渠道提供資料庫及密碼設定。

## 驗證

在本目錄執行：

```sh
python -m unittest discover -s . -p "check_*.py" -v
```

測試使用臨時資料庫與測試密碼，驗證未登入封鎖、正誤密碼、登出、嘗試頻率限制及登入後持續保存。測試不含真實學生資料或使用中的登入密碼。
